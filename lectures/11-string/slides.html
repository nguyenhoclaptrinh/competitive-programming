Bài 10: Manacher O(N) + Aho-Corasick đa mẫu

Dùng phím ← → hoặc Trước/Sau. Space dừng/phát. Phím N chạy bước tiếp theo.

1/8 — Manacher: chèn # biến mọi thứ thành lẻ

s=abba → t=^#a#b#b#a#$, tâm # là palindrome chẵn

Palindrome lẻ tâm tại ký tự, chẵn tâm giữa 2 ký tự. Chèn # + lính canh ^ $: mọi palindrome thành lẻ trên t. P[i] = bán kính = độ dài thực.

Tâm tại ký tự → palindrome lẻ. Tâm tại # → palindrome chẵn. ^ $ chặn tràn biên.

2/8 — Đối xứng C,R: kế thừa rồi mở rộng

Bấm Next: i phẩy = 2C−i, P[i] ≥ min(R−i, P[i'])
Duy trì C (tâm xa nhất), R (biên phải). Bấm Next quét i.
R chỉ tăng đơn điệu → tổng so sánh ≤ 2N.

3/8 — Code Manacher + ứng dụng

while mở rộng + cập nhật C,R
C++20 · manacher
vector<int> manacher(const string& s){
  string t="^"; for(c:s){t+='#';t+=c;} t+="#$";
  vector<int> p(m,0); int c=0,r=0;
  for(i){ int mir=2*c-i; if(r>i)p[i]=min(r-i,p[mir]);
    while(t[i+1+p[i]]==t[i-1-p[i]])p[i]++;
    if(i+p[i]>r){c=i;r=i+p[i];} } return p; }
Ứng dụng: palindrome dài nhất, đếm palindrome con, kiểm tra substring O(1).

4/8 — Aho-Corasick: Trie + failure link

link = hậu tố dài nhất cũng là tiền tố mẫu

Pattern {"ab","bc"} trên text "abc". Trie rồi BFS dựng fail. Không có cạnh c → next[fail][c] (DFA hoàn thiện, mỗi ký tự đúng 1 bước).

Fail("ab") = node "b" (hậu tố "b" là tiền tố pattern "bc"). Bấm Next duyệt text.
Đọc 'a' → node "a".

5/8 — Code Aho + search

insert + build BFS + search O(text+match)
C++20 · AhoCorasick
void build(){ queue<int> q; // BFS từ con root
  while(!q.empty()){u=q.front();q.pop();f=link[u];
    exitLink[u]=out[f].empty()?exitLink[f]:f;
    for(c){ if(next[u][c]){link[next]=next[f][c];q.push(next);}
      else next[u][c]=next[f][c]; } } } // DFA: không while lùi
📌 Tóm tắt 30 giây: Manacher = # + đối xứng C,R · Aho = Trie + fail + DFA.

6/8 — Bẫy ICPC xâu

Biên, alphabet, exitLink
  • Manacher: t dài 2n+3, ^ $ chặn tràn; p[i] có thể 0.
  • Aho: ALPHABET đúng (26/52/128). link root = 0, exitLink = 0 nếu fail không output.
  • Chuỗi exitLink dài → mỗi match O(k). Tổng O(text + matches).

7/8 — Ứng dụng nâng cao

Hash, Aho trên cây, đa alphabet
  • Manacher + hash: palindrome substring O(1).
  • Aho trên cây: DFS giữ state Aho, tìm pattern trên đường đi.
  • Đa alphabet: nén char→id hoặc unordered_map next.
